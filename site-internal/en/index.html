    RTMS Documentation¶

    Welcome to the central documentation repository for the RTMS (Real-Time Monitoring & Security) platform.

    This repository serves as the Single Source of Truth for overall system architecture, technical specifications, cross-cutting features, security compliance, and deployment guides.

    Table of Contents¶

    1. Architecture & Data Flow¶

    • Global System Overview — Architecture diagrams, components breakdown, and inter-service communication protocols.
    • Network & WireGuard Guide — Multi-site tunneling and scanner connectivity via WireGuard.
    • RBAC Security Model — Role-based access control specifications and permission matrices.
    • Database Security & RBAC — PostgreSQL role hardening, privileges, and connection security.
    • Data Models:
    • Scanner Data Model — Probing database schema, host discovery tables, and scan results.
    • NVD Data Model — CVE database schema, CPE mappings, and CVSS scoring tables.

    2. Deployment & Installation¶

    • Ansible Deployment Guide — End-to-end automated provisioning, hardening, and container setup.
    • PostgreSQL Hardening Guide — Production database configuration, security policies, and performance tuning.

    3. Component Technical Documentation¶

    Detailed technical specifications for each individual subsystem: * RTMS Scanner (rtms-scanner): * Technical Requirements * Mobility, Lifecycle & Multi-Network * Standalone Mode Guide * Versions & Changelog * Docker & PyInstaller * Bettercap Commands * Email & DNS Audits * Granular Deep Scan Targeting * Resources & HTTP Testing * RTMS Web (rtms-web): * Web Platform Technical Documentation — FastAPI endpoints, React frontend architecture, WebSocket feeds. * SOC / SIEM Threat Correlation Guide — Multi-provider architecture (Splunk, Wazuh, Suricata, Sentinel, CrowdStrike), risk scoring engine, and REST APIs. * Threat Dashboard User Guide — Exposure dashboard navigation, contextual scoring, and SOC provider configuration. * Production Nginx & Frontend Setup * Enterprise SSO Keycloak & OIDC Integration * Web Backend Startup Guide * RTMS Local Agent (rtms-local-agent): * Agent Technical Architecture — Host metrics, package inventory, and process polling. * Agent Installation Guide * RTMS NVD Microservice (rtms-nvd): * NVD Service Documentation — Local CVE mirror and lookup engine. * Installation Guide * Startup & Ingestion Guide * Exporting CVE Reports * RTMS Admin & CLI (rtms-admin): * Admin Tools & Management

    4. Extensible Plugin Framework¶

    • Plugin Specification & Developer Guide — Architecture of the hot-reloadable Python security plugin system, AST safety validator rules, lifecycle hooks, and plugin authoring tutorial.

    5. Governance, Compliance & Legal¶

    • NIS2 Compliance Specification — Complete mapping of RTMS security controls to the European NIS2 Directive articles.
    • Cyber Resilience Act (CRA) — CRA regulatory compliance and vulnerability management requirements.
    • Release & Versioning Strategy — Semantic versioning and deployment lifecycle across the RTMS stack.
    • Software Licenses & Legal Notices — Licensing terms, third-party libraries, and proprietary software copyrights.
    • Legal Documents:
    • End User License Agreement (EULA)
    • Applied Standards
    • EU Declaration Template
    • Risk Assessment

    Repository Ecosystem¶

    git_projects/
├── rtms-documentation/    # Central documentation portal (this repository)
├── rtms-web/              # Central Web Dashboard & REST API
├── rtms-scanner/          # Network discovery & auditing probe engine
├── rtms-commons/          # Shared Python libraries & AST plugin validator
├── rtms-local-agent/      # Deep inspection endpoint agent
├── rtms-nvd/              # Offline CVE ingestion and search service
├── rtms-installer/        # Automation scripts & systemd services
└── rtms-admin/            # Central administration CLI & WireGuard tools

    Developer Note: Each individual repository contains a concise README.md covering local environment setup (uv sync, npm install), test suites (pytest), and environment variables.
